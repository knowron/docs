# Product Passport

*Ihre Dokumentation, nur einen Scan entfernt.*

Der Product Passport gibt jeder Maschine oder jedem Produkt eine eigene URL, die durch Scannen eines QR-Codes am physischen Gerät erreichbar ist. Kunden, Partner und Servicetechniker scannen den Code, geben bei Bedarf einen 8-stelligen Key Code ein und gelangen direkt zur passenden Dokumentation für genau dieses Gerät. Für öffentliche Inhalte sind kein Konto, keine Anmeldung und kein Support-Ticket erforderlich.

## Warum ein Product Passport

- **Entlasten Sie Ihre Support-Kanäle.** Kunden und externe Servicetechniker erreichen die passende Dokumentation für genau die Maschine vor ihnen, indem sie einen Code scannen, und erhalten ihre Antwort in Sekunden, ohne Ihr Team zu kontaktieren. So rufen weniger von ihnen an, schreiben E-Mails oder eröffnen Tickets, um an das zu gelangen, was sie brauchen.
- **Teilen Sie Dokumentation, die immer aktuell ist.** Ein QR-Code verweist stets auf die aktuelle Version jedes Dokuments. Einmal aktualisieren, und jeder, der scannt, sieht die neueste Version, ohne Neudrucke und ohne veraltete PDFs im Umlauf.
- **Konzentrieren Sie sich darauf, was wen erreicht, nicht auf die Bereitstellung.** Sie entscheiden, welche Inhalte jede Zielgruppe sieht. KNOWRON übernimmt Hosting, Verfügbarkeit und Auslieferung, damit Ihr Team seine Zeit in die Dokumentation steckt statt in Infrastruktur, die nicht zu Ihren Kernkompetenzen gehört.

## Digitale Produktpässe und EU-Konformität

Der Product Passport ist auf zwei regulatorische Entwicklungen ausgelegt, die die Produktdokumentation in Richtung digitaler Aufzeichnungen verschieben. Beide sind voneinander getrennt, und der Passport unterstützt beide.

- Die **EU-Maschinenverordnung (EU 2023/1230)** erlaubt es, Betriebsanleitungen digital statt nur auf Papier bereitzustellen. Sie gilt ab dem 20. Januar 2027.
- Der **digitale Produktpass (DPP)**, eingeführt über die EU-Ökodesign-Verordnung für nachhaltige Produkte (ESPR, EU 2024/1781), wird für eine wachsende Zahl von Produktkategorien einen strukturierten digitalen Datensatz je Produkt vorschreiben, schrittweise über die kommenden Jahre eingeführt.

Die beiden Regelungen getrennt halten: Die Maschinenverordnung betrifft digitale Betriebsanleitungen, der DPP ergibt sich aus der ESPR. -->

Für digitale Betriebsanleitungen nach der Maschinenverordnung muss die Dokumentation:

- leicht zugänglich sein
- frei von Bezahlschranken sein
- mindestens 10 Jahre nach dem Inverkehrbringen der Maschine verfügbar sein

KNOWRON übernimmt die Infrastruktur hinter diesen Anforderungen: langfristiges Hosting, Versionskontrolle der Dokumente, maschinengenaue Zuordnung und garantierte Verfügbarkeit über den gesamten Konformitätszeitraum. Der QR-Code bleibt gleich, auch wenn die Dokumentation aktualisiert wird, sodass kein Neudruck nötig ist.

!!! tip "Mehr als nur Konformität"
    Eine gut strukturierte Passport-Seite ist außerdem ein digitaler Touchpoint für Support, Vertrieb und Marketing. Jede ausgelieferte Maschine wird zu einem direkten Kanal zu Ihren Kunden.

## Zentrale Funktionen

| Funktion | Details |
|---|---|
| **QR-Codes je Maschine** | Jede Maschine erhält einen eindeutigen, dauerhaften QR-Code, den Sie am physischen Gerät anbringen |
| **Gestufte Zugriffssteuerung** | Eine URL, drei Sichtbarkeitsstufen. Sie legen fest, was jede Zielgruppe sieht |
| **Zugriff per Key Code** | Geschützte Inhalte werden mit einem 8-stelligen Key Code freigeschaltet, entweder je Maschine oder als Master Key Code für eine ganze Flotte |
| **KI-Assistent auf dem Passport** | Besucher können Fragen stellen, und der Assistent antwortet aus den Quellen, die Sie auf diesem Passport freigeben |
| **Assistent-Credits** | Die Nutzung des Assistenten greift auf ein Credit-Kontingent zu. Ist es aufgebraucht, bleiben die Dokumente zugänglich. |
| **Langfristiges Hosting** | KNOWRON garantiert Verfügbarkeit und Dokumentenzugang über den gesamten Konformitätszeitraum |
| **Versionskontrolle** | Dokumentenaktualisierungen erscheinen automatisch, ohne dass QR-Codes neu gedruckt oder neu verteilt werden müssen |

## Was eine Passport-Seite enthält

Jede Passport-Seite ist einer bestimmten Maschine oder einem bestimmten Produkt zugeordnet und kann Folgendes enthalten:

- **Technische Maschinendaten.** Technische Daten, Abmessungen, Leistungswerte und weitere wichtige Attribute. Diese werden automatisch aus der Gerätenummer und den Produktattributen befüllt, die Sie beim Onboarding eingeben.
- **Einen externen Link** Ihrer Wahl, zum Beispiel Ihr Support-Portal oder Ihre Produktseite.
- **Zugang zum KI-Assistenten**, der aus den für diese Maschine freigegebenen Quellen antwortet.
- **Ausgewählte Wissensinhalte.** Die konkreten Inhalte, die Sie freigeben, gefiltert nach Sichtbarkeit.

## Drei Zugriffsebenen aus einem QR-Code

Derselbe QR-Code kann je nach Person, die ihn scannt, und je nach vorliegendem Key Code drei verschiedene Informationsebenen liefern. Über die Sichtbarkeitseinstellungen steuern Sie, was jede Zielgruppe sieht.

<p align="center"><img src="https://i.imgur.com/1ETa9nL.png" width="80%"></p>


### 🌎 Öffentlich

Jede Person mit physischem Zugang zur Maschine kann den Code scannen und ohne Key Code auf öffentliche Inhalte zugreifen. Diese Ebene wird nicht von Suchmaschinen indexiert.

**Am besten für:** Marketingbroschüren, Konformitätsdokumente wie Konformitätserklärungen und Zertifikate, Maschinenspezifikationen und allgemeine Produktinformationen.

### 🏠 Kunden

Ihre Kunden schalten mit einem Key Code eine tiefere Ebene frei. Ein Key Code je Maschine öffnet ein einzelnes Gerät, ein Master Key Code öffnet eine ganze Flotte. So erreichen Serviceteams im Feld mit einem einzigen Code die Dokumentation jeder abgedeckten Maschine. Diese Ebene steht Ihren Kunden zur Verfügung, und nur Ihren Kunden.

**Am besten für:** Bedienungs- und Wartungsanleitungen, Ersatzteillisten, Support-Kontaktdaten, allgemeine Fehlerbehebungsanleitungen und How-tos.

### 🔒 Intern

Authentifizierte Mitarbeitende Ihrer Organisation sehen das vollständige Bild innerhalb Ihrer KNOWRON-Instanz. Diese Inhalte sind über den anonymen Passport-Zugang nie erreichbar.

**Am besten für:** F&E-Notizen, interne Servicemitteilungen, tiefergehende Fehlerbehebung, Wartungsprotokolle und Erfahrungswissen erfahrener Kolleginnen und Kollegen.

## Der Passport-Assistent

Der Passport-Assistent antwortet aus allen zulässigen Inhaltstypen, die Sie freigeben, gefiltert nach Sichtbarkeit: Dokumente, Artikel, Tutorials und Expertenantworten. Inhalte, die für den Passport-Kontext nicht zulässig sind (Intern), werden nie zurückgegeben und erscheinen nie in den Quellen.

Die Nutzung des Assistenten greift auf ein Credit-Kontingent zu.
